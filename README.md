# New York · September 2026

PWA móvil del itinerario privado de Nueva York.

## Publicar en GitHub Pages

1. Sube estos archivos a la rama `main`, en la raíz del repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona `main` y `/ (root)`, y guarda.

Todos los enlaces y recursos usan rutas relativas, por lo que la aplicación funciona tanto en un dominio propio como en un subdirectorio de GitHub Pages.
